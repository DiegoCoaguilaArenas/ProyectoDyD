# Portal de Noticias DDP - Gestor de Contenidos Dinámico

Este repositorio contiene el código fuente completo del Portal de Noticias DDP (Diálogo y Desarrollo Perú), una plataforma web dinámica orientada al periodismo independiente. Incluye un sitio web para los lectores y un panel de administración personalizado.

## Enlaces del Proyecto

- **Sitio Web en Vivo:** https://proyectodyd-production.up.railway.app/index.php
- **Panel de Administración:** https://proyectodyd-production.up.railway.app/revista-admin/

## Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 4.
- **Backend:** PHP 7/8 (PDO).
- **Base de Datos:** MySQL.
- **Despliegue:** GitHub, Railway
- **Integraciones:** Spotify & YouTube iframe API (Podcasts y Videos).

## Características Principales

1. **Gestor de Reportajes:** Creación, edición, vista previa y publicación de artículos con editor de texto enriquecido.
2. **Sistema de Estados:** Los reportajes en estado "Borrador" solo son visibles para administradores autenticados.
3. **Multimedia Integrada:** Reproductores interactivos en ventanas emergentes (modales) para podcasts y videos.
4. **Filtros de Archivo:** Agrupación dinámica de reportajes por mes y año (`GROUP BY`).
5. **URLs Amigables (SEO):** Soporte para slugs y etiquetas Open Graph.
6. **Diseño Responsive:** Adaptable a dispositivos móviles y tablets.
